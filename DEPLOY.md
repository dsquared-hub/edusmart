# Боевой запуск

Пошагово: от пустого сервера до работающих бота и сайта на HTTPS с
резервными копиями. Затем — юридический чек-лист, без которого запускать
продукт для детей нельзя.

## 1. Сервер

- **Где:** дата-центр **на территории Узбекистана**. Закон «О персональных
  данных» требует хранить персональные данные граждан Узбекистана на
  серверах внутри страны. Спроси у провайдера письменное подтверждение, где
  физически стоит сервер.
- **Какой:** VPS с Ubuntu 22.04/24.04, 2 vCPU, 4 ГБ RAM, 40 ГБ SSD — хватит
  на первые тысячи учеников.
- **Домен:** например `edu.example.uz`. A-запись домена → IP сервера.

## 2. Установка

```bash
# на сервере
sudo apt update && sudo apt install -y docker.io docker-compose-v2 git
sudo usermod -aG docker $USER && newgrp docker

git clone <адрес репозитория> edu && cd edu
cp .env.example .env
nano .env
```

Обязательно заполни в `.env`:

| Переменная | Что указать |
| --- | --- |
| `DOMAIN` | твой домен, например `edu.example.uz` |
| `BOT_TOKEN`, `BOT_USERNAME` | из @BotFather |
| `OWNER_ID` | свой Telegram ID (команда `/myid` в боте) |
| `GEMINI_API_KEY` | ключ Google AI Studio |
| `POSTGRES_PASSWORD` | длинный случайный пароль |
| `JWT_SECRET` | `python3 -c "import secrets; print(secrets.token_urlsafe(48))"` |
| `OPERATOR_NAME`, `OPERATOR_CONTACT`, `DATA_LOCATION` | для страницы политики |

`WEB_URL` и `CORS_ORIGINS` для боевого запуска подставляются из `DOMAIN` автоматически.

## 3. Запуск

```bash
cd deploy
docker compose -f docker-compose.prod.yml --env-file ../.env up -d --build
docker compose -f docker-compose.prod.yml --env-file ../.env ps     # все сервисы healthy/running
curl https://$DOMAIN/api/health                                        # {"ok":true,"db":true}
```

Caddy сам получит и будет продлевать сертификат Let's Encrypt (нужны
открытые порты 80 и 443). Миграции базы применяются при каждом старте API.

## 4. Telegram

В @BotFather:

1. `/setdomain` → выбери бота → укажи домен. Без этого не работает кнопка
   «Войти через Telegram» на сайте.
2. `/setmenubutton` → URL `https://<домен>/`. У бота появится кнопка
   Mini App (сайт внутри Telegram, вход автоматический).

Кнопки «🌐 Открыть на сайте» в боте включаются сами, когда `WEB_URL` на HTTPS.

## 5. Перенос данных со старого бота

```bash
docker compose -f docker-compose.prod.yml --env-file ../.env cp /путь/education_bot.db backend:/tmp/old.db
docker compose -f docker-compose.prod.yml --env-file ../.env exec backend \
    python scripts/migrate_sqlite_to_pg.py /tmp/old.db --dry-run
docker compose -f docker-compose.prod.yml --env-file ../.env exec backend \
    python scripts/migrate_sqlite_to_pg.py /tmp/old.db
```

Согласия из старого бота переносятся с версией `legacy`: родителей попросят
подтвердить согласие на новую политику (одна кнопка в боте).

## 6. Резервные копии

- Сервис `backup` делает `pg_dump` раз в сутки в `deploy/backups/` и
  хранит 14 дней (`BACKUP_KEEP_DAYS`).
- **Копируй `deploy/backups/` на другой сервер** (тоже в Узбекистане):
  копия на том же диске не спасёт при поломке сервера. Например, cron +
  `rsync` раз в сутки.
- Восстановление: `cd deploy && sh restore.sh backups/edu-ГГГГММДД-ЧЧММСС.dump`.
- **Раз в месяц проверяй восстановление** на тестовом сервере: копия,
  из которой ни разу не восстанавливались, — не копия.

## 7. Мониторинг

- `https://<домен>/api/health` проверяет API и базу. Подключи бесплатный
  внешний мониторинг (UptimeRobot, Better Stack и т.п.) с уведомлением в
  Telegram, если ответ не 200.
- Логи: `docker compose -f docker-compose.prod.yml --env-file ../.env logs -f backend bot`.
- Жалобы «⚠️ Здесь ошибка» приходят владельцу в Telegram, список — `/reports`.

## 8. Обновление

```bash
git pull
cd deploy && docker compose -f docker-compose.prod.yml --env-file ../.env up -d --build
```

## 9. Юридический чек-лист (с юристом, до запуска для реальных детей)

Это не юридическая консультация. Список вопросов, которые нужно закрыть
с юристом, знающим законодательство Узбекистана.

- [ ] **Локализация данных.** Сервер и резервные копии физически в
      Узбекистане (закон «О персональных данных» № ЗРУ-547, статья о
      хранении данных граждан на территории РУз).
- [ ] **Регистрация базы персональных данных** в государственном реестре,
      если это требуется для вашей организации.
- [ ] **Оператор.** Юрлицо или ИП, которое отвечает за данные. Укажи в
      `OPERATOR_NAME`, `OPERATOR_CONTACT`.
- [ ] **Текст политики.** Страница `/privacy` — шаблон на трёх языках.
      Юрист должен проверить и дописать его. После изменений увеличь
      `POLICY_VERSION`: родители подтвердят согласие заново, журнал
      (`consent_records`) сохранит, кто и на какую версию согласился.
- [ ] **Передача в Google Gemini.** Текст вопроса и фото уходят в Google
      (серверы вне Узбекистана). Это трансграничная передача: юрист
      должен решить, достаточно ли согласия родителя и описания в политике,
      или нужен другой провайдер ИИ/сервер в стране. Имя и прогресс ребёнка
      в Google не передаются.
- [ ] **Согласие родителя** даётся в боте и записывается в журнал. Проверь,
      достаточно ли этой формы (кнопка в Telegram) для детей вашего возраста.
- [ ] **Удаление данных.** Родитель удаляет данные ребёнка в боте
      («Профиль» → «Удалить данные»). Резервные копии очищаются через
      `BACKUP_KEEP_DAYS` дней — это должно быть указано в политике (указано).
- [ ] **Договор с провайдером хостинга** об обработке персональных данных.
