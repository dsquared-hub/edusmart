# EDU ProgressUZ — интерактивный прототип

Кликабельный прототип образовательной экосистемы для школьников Узбекистана 1–11 классов:
ИИ-помощник объясняет темы школьной программы по шагам, а маскот **Куби** растёт
и одевается лучше, когда ученик решает задачи.

## Запуск

Нужен Node.js 20+.

```bash
cd prototype
npm install
npm run dev        # http://localhost:5173 (и адрес в локальной сети — для телефона)
```

Сборка для показа (статические файлы в `dist/`, открываются любым веб-сервером):

```bash
npm run build
npm run preview    # http://localhost:4173
```

Полезные параметры адреса:

| Адрес | Что делает |
| --- | --- |
| `/?demo` | Сразу в приложение, без регистрации (для презентаций) |
| `/?demo=dark`, `/?demo=light` | То же + тёмная или светлая тема |
| `/?demo&lang=ru` | Язык: `uz`, `ru`, `en` |
| `#/onboarding` | Регистрация по номеру телефона |

Прогресс, монеты и настройки хранятся в `localStorage` браузера: сбросить можно
в «Профиль → Выйти».

## Концепция дизайна

**Тёплая «кофейно-молочная» палитра** — дорого и уютно одновременно, без кричащих
детских цветов. Объём — мягкими 3D-иконками, 3D-монетами и объёмным Куби, без тяжёлого WebGL.

**Куби** — собственный блочный персонаж (в духе «кубических» игровых аватаров, но
оригинальный). 7 этапов образа: Новичок → Ученик → Отличник → Знаток → Эксперт →
Мастер → Легенда (костюм, часы, медаль и золотая аура). Реагирует на события:
радуется верному ответу, поддерживает после ошибки — **никогда не грустит и не стыдит**.

**Против «тёмных паттернов» Duolingo** (блок «Почему EDU ProgressUZ» на главной и в онбординге):
ошибок без лимита и монеты за исправление, мягкие настраиваемые напоминания,
бесплатная заморозка серии и выходные, монеты за понимание, без рекламы,
программа школ Узбекистана, кабинеты родителя и учителя.

**Два режима подачи** на одной дизайн-системе: Junior (крупнее, мягче, больше анимаций)
и Senior (плотнее, сдержаннее). Переключается в профиле, выбирается автоматически по классу.

## Карта экранов

```
Онбординг: приветствие + «Почему мы» → телефон (+998) → SMS-код (6 полей) → роль → имя, класс, язык, цвет Куби
Ученик
├── Главная — приветствие, Куби, уровень, серия + заморозка, задания дня, «Продолжить», «Задать вопрос»
├── Задать вопрос ★ — текст / фото с рамкой обрезки / голос; шаги по одному; «Объясни проще»,
│                     «Покажи пример», «Проверь меня»; задача на закрепление с монетами
├── Предметы — 12 предметов с 3D-иконками и прогрессом
├── Учебники → Читалка — выдели фрагмент → «Спросить ИИ»
├── Тесты — выбор ответа, верно/неверно, ввод; ∞ попыток, разбор ошибок
├── Прогресс — активность (график), шкала уровней, освоение тем, карта сильных/слабых тем, история
├── Рейтинг — класс / школа / регион, пьедестал с аватарами
├── Достижения — коллекция медалей
├── Гардероб — 7 этапов, закрытые силуэтом с замком и ценой, покупка за монеты + конфетти
└── Профиль — язык, тема (светлая/тёмная/системная), Junior/Senior, напоминания, заморозка серии
Кабинет родителя — ребёнок, время занятий, слабые темы, последние занятия, отчёт, напоминания
Кабинет учителя — классы, ученики с прогрессом, частые вопросы класса, выдача задания
Дизайн-система — витрина токенов и компонентов
```

## Структура

```
src/
├── design-system/   tokens.css (цвета, радиусы, режимы, темы) и components.tsx
├── components/      avatar/Kubi.tsx, layout/AppShell.tsx, Formula, WhyBlock, Confetti
├── pages/           по одному файлу на экран
├── locales/         uz.ts, ru.ts, en.ts — все тексты; ключи проверяет TypeScript
├── mock-data/       предметы, учебники, объяснение ИИ, тесты, рейтинг, ученики
└── lib/             store (состояние, монеты, настроение Куби), router, useThemeColors
```

## Технологии

React 18 + TypeScript + Vite, Tailwind CSS (цвета — CSS-переменные, темы переключаются
атрибутом `data-theme`), Framer Motion (микроанимации, полёт монет, конфетти), Recharts
(графики), Lucide (иконки). Анимации отключаются системной настройкой
`prefers-reduced-motion` и переключателем «Меньше анимаций» в профиле.

## Что это не делает (прототип)

ИИ-ответы, SMS и данные — демонстрационные: объяснение про трапецию, фото и голос
«распознаются» в заранее заданный вопрос, любой SMS-код подходит. Для боевой версии
эти места подключаются к настоящему API (см. основной проект в корне репозитория).
